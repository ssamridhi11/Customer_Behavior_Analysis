# Customer Behavior Data Analyst Project
This project is a complete, industry standard, end to end data analytics workflow, designed to mirror the real responsibilities of a professional analyst in modern business environments.

The project encompasses all critical stages of data analysis, from Data preparation and
modeling to insight generation, visualization and reporting.

## Overview

### Goal
To simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence tool.

### Roadmap
- Data presentation, Modeling and Exploratory Data Analysis using pandas(Python): Cleaned and transformed the raw dataset for analysis.

- Data Analysis(SQL): Simulated business transactions, run queries to extract insights on customer segments, loyalty, and purchase drivers.

- Visualisation and Insights(Power BI): Built an interactive dashboard that highlights key patterns and trends, enabling refinement in decision makig process for stakeholders.

- Reporting and Visuals: Wrote a clear project report summarizing business problem, key findings and business predictions and recommendations, made a visual to clearly communicates insights and actionable recommendations to stakeholders.

### How to Use This Project

1 Clone the repository

    git clone https://github.com/ssamridhi11/Customer_Behavior_Analysis.git

    cd Customer_Behavior_Analysis

2 Open CustomerBehaviorAnalysis.ipynb notebook

    This file contains:

    Data Import

    Data exploration

    Data cleaning

    Connection to SQL Database

3 Load the data from Python notebook into MySQL/PostgreSQL/MS SQL Server

    Create a database in SQL

    Run Python code to load data into SQL database

    Open customerbehavior.sql

    Answer Business Questions using SQL Queries

4 Connect the SQL Database to Power BI

    Open customerBehaviorDashboard.pbix

    Create interactive dashboard in Power BI

5 Create project and delivery

    Create Project Report and Presentation/Visual

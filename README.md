# Customer Behavior Data Analyst Project
This project is a complete, industry standard, end to end data analytics workflow, designed to mirror the real responsibilities of professional analysts in modern business environments.
The project encompasses all critical stages of data analysis, from Data preparation and modeling to insight generation, visualization and reporting.

## Overview
### Goal
To simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence by:

- Data presentation, Modeling and Exploratory Data Analysis using pandas(Python): Clean and transform the raw dataset for analysis.

- Data Analysis(SQL): Simulate business transactions, run queries to extract insights on customer segments, loyalty, and purchase drivers.
